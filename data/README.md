# Spieldaten

JSON enthält ausschließlich Daten, keine Spiellogik:

- `levels/` – Plattformen, Gegnerzonen und Landschaftsabschnitte
- `upgrades.json` – verfügbare Upgrade-Karten, Seltenheiten und Ziehgewichte
- `asset-manifest.json` – verbindliche Laufzeitdateien, Raster und Framezahlen
- `asset-credits.json` – Herkunft und Nutzungsnotizen aller Assets
